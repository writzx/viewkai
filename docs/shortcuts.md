# viewkai Keyboard Shortcuts

| Shortcut | Scope | Action | Notes |
|---|---|---|---|
| `Ctrl+O` | app / web | Open File… | Native: file dialog; Web: file input |
| `Ctrl+L` | app / web | Open from URL… | URL fetch dialog |
| `Ctrl+W` | app / web | Close document | |
| `Ctrl+Q` | native app only | Exit | No-op on web |
| `Ctrl+Shift+O` | app / web | Toggle Outline sidebar | |
| `Ctrl+Shift+T` | app / web | Toggle Thumbnails sidebar | |
| `Ctrl+Shift+L` | library | Rotate all pages counter-clockwise | Disabled by set_library_shortcuts_enabled(false) |
| `Ctrl+Shift+R` | library | Rotate all pages clockwise | Disabled by set_library_shortcuts_enabled(false) |
| `Ctrl+F` | library | Open search | Plan 02 |
| `Ctrl+A` | library | Select all text | Plan 02 |
| `Ctrl+C` | library | Copy selection | Plan 02 |
| `F3` / `Shift+F3` | library | Find next / previous | Plan 02.5 |
| `Cmd+G` / `Cmd+Shift+G` | library | Find next / previous (macOS) | Plan 02.5 |
| `PgUp` | library | Previous page (Single mode) | |
| `PgDn` | library | Next page (Single mode) | |
| `Home` | library | First page (Single mode) | |
| `End` | library | Last page (Single mode) | |
| `Ctrl+Left` | library | Previous spread (Spread mode) | |
| `Ctrl+Right` | library | Next spread (Spread mode) | |
